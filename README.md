# RelayMe — ad pipeline

Makes vertical and square video ads by photographing the **live site** in a
headless browser and compositing the result. Nothing in these ads is a mockup
screen: every frame is the real page at `relayme.bio`.

---

## Setup, once

```
pip install playwright pillow requests
python -m playwright install chromium
```

ffmpeg has to be reachable. If it is not on PATH, point at it per session:

```
$env:FFMPEG="C:\Program Files (x86)\Tenorshare iCareFone\ffmpeg.exe"
```

Then build the mascot, doodles and hand mockup — once, about 30 seconds:

```
python make_ad.py --assets
```

---

## Making an ad

```
python make_ad.py <name> [format]
```

Seven ads:

| Name | Length | Style | What it shows |
|---|---|---|---|
| `nine-services` | 15.0s | drawn phone | The nine embed services, as a launch ad |
| `one-page` | 15.0s | drawn phone | The general pitch — evergreen, good as a pinned post |
| `giveaway` | 11.7s | drawn phone | The Pro giveaway. Deadline 30 September 2026 |
| `features` | 13.0s | hand | Quiet feature tour |
| `features-players` | 13.3s | hand | Eight services opening in turn, then video |
| `features-layout` | 11.3s | hand | Socials, headings, dividers, icons, sign-up |
| `features-blog` | 9.7s | hand | Blog index, a post, the Linktree comparison |

Three formats. `9:16` is the default:

| Format | Size | For |
|---|---|---|
| `9:16` | 1080×1920 | Reels, TikTok, Stories |
| `4:5` | 1080×1350 | Instagram feed — takes the most feed height |
| `1:1` | 1080×1080 | Square feed, LinkedIn |

So a feed post and a Reel of the same ad:

```
python make_ad.py features-players 4:5
python make_ad.py features-players 9:16
```

**The second one is fast.** Captures are shape-independent and cached per ad in
`_shots_<name>`, so only the first render of an ad pays the ~6 minute capture.
Every other format is a re-render, about two minutes.

Delete `_shots_<name>` to force a fresh capture. You must do that after changing
a shot's `url`, `scroll` or `click_poster`, because those live in the capture
rather than the render. Caption and timing changes need no re-capture.

---

## Two styles

**Drawn phone** — the device is drawn in code. Dark violet ground, lime end card
with a call to action. These are adverts.

**Hand** — the real photographed hand from `hand-mockup.jpg`, light ground, no
end card and no pitch. These are feature tours. The light ground is deliberate:
a photographed hand on a dark gradient looks pasted on.

---

## Adding an ad

Ads are data. Copy an entry in `ADS` near the top of `make_ad.py` and change the
shots. A shot is a URL, a caption, a hold length in frames (30 = 1 second), and
optionally a `scroll` target or a `click_poster` index.

Give it `"style": "hand"` for a feature tour, or an `"end"` block for an advert
with a closing card. One or the other, never both.

**Write captions against what is actually on the page.** An earlier cut said
"A thumbnail per link", which was false — no link on the official page has an
image set, so those row icons are favicons. Check before you claim.

## Things that will bite

**The phone is 0.461 wide to tall.** Captures run at a 430×932 viewport for that
reason. An early version used 520×924 — that is 9:16, and no amount of resizing
made it look like a phone. It was the wrong shape, not the wrong size.

**Poster indices shift.** `click_poster` is a position in the page's list of play
buttons. Adding or reordering links on the live page moves them. The capture
prints what it found; index 4 is skipped on purpose, being a second YouTube link.

**Transitions move only what changes.** The screen slides and cross-fades inside
the phone while the shell and background hold still. An earlier version dissolved
whole frames and ghosted badly — two near-identical pages blended, doubling every
caption.

**Text auto-shrinks to fit.** Nothing may touch the edge, so a long caption steps
down in size rather than running off. Do not hand-tune sizes to compensate.

**The giveaway wording is legal, not marketing.** "Twenty best answers win" keeps
it a Polish *konkurs* rather than a *loteria promocyjna*, which would need a
permit. Do not reword it as a prize draw.

**The mascot comes from `app/blob.tsx`** in the app repo, rasterised at build
time. If it changes there, update `MASCOT_SVG`. Never redraw it by eye.

---

## What not to commit

`.gitignore` covers it. Everything ignored is regenerated by the script —
captures, frames, assets, the font and the finished MP4s. A single ad is ~400
PNGs and a 4 MB video, so committing output would bloat this repo quickly.

The source is just `make_ad.py`, `hand-mockup.jpg` and this file.
